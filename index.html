运行模式说明：当前开箱运行的是确定性仿真推理源，用于完整演示系统交互、可视化、对比与复述能力，不依赖摄像头、模型权重或 GPU。要接入真实 YOLOv8 权重，按下方步骤启动 inference/yolov8_service.py 并在界面「推理源」处切换；前端决策链与 JSON 契约保持一致，无需改动 UI。

系统架构

采集层
正面相机（人脸 / 下颚带）+ 斜上方相机（盔体 / 破损），由闸机红外信号同步取帧
身份层
人脸活体 + 1:N 比对，返回工号、工种、授权帽色
检测模型
yolov8s-seg / detect：头部、安全帽、人脸、下颚带四类目标
颜色分支
盔体 mask 内 HSV 主色 + yolov8s-cls 复核，输出颜色 → 等级映射
破损分支
盔体裁剪放大至 512 后分类（完好 / 裂纹 / 凹陷 / 缺口 / 老化），可叠加 OBB 检测裂纹
姿态分支
yolov8s-pose 取耳、鼻、头顶、下巴关键点 + 几何覆盖规则
决策层
五条规则串联，任一未通过即拒闸；支持规则开关做策略对比
执行层
开闸 / 声光报警 / 抓拍留证 / 台账记录 / 安保复核

接入真实 YOLOv8

  1. 安装依赖：pip install -r inference/requirements.txt
  2. 放置训练权重：inference/weights/detect.pt、cls_color.pt、cls_damage.pt、pose.pt
  3. 启动服务：python inference/yolov8_service.py --port 8000
  4. 浏览器控制台执行：App.setSource('http://127.0.0.1:8000')
  5. 服务 /infer 返回与本系统一致的 JSON，决策链自动复用
# 训练示例（Ultralytics）
yolo detect train model=yolov8s.pt data=helmet.yaml imgsz=960 epochs=150 batch=16
yolo segment train model=yolov8s-seg.pt data=helmet_seg.yaml imgsz=960 epochs=120
yolo classify train model=yolov8s-cls.pt data=helmet_color imgsz=224 epochs=80
yolo pose train model=yolov8s-pose.pt data=head_kpt.yaml imgsz=640 epochs=100

数据与验收建议

  • 标注：目标框 / 掩码 + 颜色属性 + 破损属性 + 佩戴状态 + 人员 ID，导出 YOLO 格式与属性 JSON
  • 增强：强光、夜间补光、扬尘、反光、污渍、口罩遮挡、多人同框
  • 验收：帽检出 recall ≥ 99%，佩戴判定 ≥ 97%，颜色 ≥ 98%，破损召回 ≥ 95%，端到端 < 500 ms，误放行 = 0
  • 破损检测最难，优先保召回；小缺陷需高分辨率裁剪与真实破损样本微调
  • 断网降级：本地白名单缓存、恢复后补传；保留人工开闸与消防应急模式
  • 合规：人脸与抓拍按最小必要采集、加密存储、设置保留期与访问审计
