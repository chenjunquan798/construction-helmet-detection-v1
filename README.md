# 工地入口安全帽佩戴检测系统 · V1

基于 **YOLOv8** 的工地员工通道「刷脸 + 安全帽」联动检测系统可视化原型（第一代）。

对应需求：安全帽颜色等级区分、盔体破损检测、是否正确佩戴判定，并与闸机刷脸系统联动。

> 仓库定位：可交互的系统原型 / 方案验证平台。开箱运行的是**确定性仿真推理源**，无需摄像头、权重与 GPU 即可完整演示；真实 YOLOv8 的接入层已预留，见下文。

---

## 四个核心能力

| 能力 | 实现 |
| --- | --- |
| **能看** | SVG 闸机通道画面：人物、安全帽（按等级变色）、裂纹 / 凹陷 / 帽檐缺口、下颚带状态、反戴 / 手持 / 倾斜，可叠加检测框、姿态关键点、顶部相机俯视图；四路 YOLOv8 输出卡片实时显示置信度 |
| **能跑** | 纯前端零依赖，双击 `index.html` 即可运行。12 个场景预设 + 6 名员工 + 5 个可调阈值 + 5 个规则开关，改参数立即重算 |
| **能对比** | A/B 场景并排（逐项规则差异高亮）、阈值灵敏度曲线、批量仿真（完整四任务方案 vs「仅检测有无帽」传统方案） |
| **能复述** | 每次检测自动生成四段中文报告：采集 → 四路模型推理 → 五条规则决策链 → 结论处置；支持复制、导出 txt、台账「复述重放」 |

## 决策链

```
人脸活体 / 1:N 比对  →  帽在  →  佩戴规范  →  盔体完好  →  帽色与授权等级一致
                        任一不通过即拒闸
```

```python
if not face.live or face.score < 0.70:      return "RETRY"          # 重新刷脸
if not helmet.present:                      return "DENY_NO_HELMET"
if not wear.correct:                        return "DENY_WEAR"
if damage.prob > 0.50:                      return "DENY_DAMAGED"   # 转人工复核
if helmet.color != user.authorized_color:   return "DENY_GRADE"
return "ALLOW"
```

所有拒绝事件抓拍并记录时间 / 通道 / 工号 / 原因，支持事后追溯，并保留「安保放行」兜底入口。

## 技术设计要点

- **颜色与等级**：颜色等级做成项目配置项（白=管理/监理，黄=普工，蓝=技术/特种作业，红=消防/安全/访客），不写死在模型里。刷脸成功后从人事系统取 `authorized_color` 比对，不一致按「越权佩戴」处理。
- **破损检测**：先由检测模型裁出盔体，再送高分辨率分类 / OBB 模型判「完好 / 裂纹 / 凹陷 / 缺口 / 老化」；顶部相机看裂纹凹陷、侧面相机看帽檐缺口与下颚带。指标优先保召回率，触发后转人工复核。
- **正确佩戴**：检测头部框、安全帽框、人脸框、下颚带，配合姿态关键点做几何规则判定（覆盖率、帽前沿位置、左右偏移、下颚带系紧、朝向），排除手持、挂背后、反戴、未扣带。
- **四路 YOLOv8 子任务**：`detect`（目标/掩码）、`cls-color`（颜色等级）、`cls-damage`（破损，盔体裁剪后分类）、`pose`（姿态关键点），可独立迭代。

## 快速开始

```bash
# 方式一：直接双击 index.html（零依赖）
# 方式二：起本地静态服务
python -m http.server 8765
# 浏览器打开 http://127.0.0.1:8765/
```

打开后切换到 **实时监控** 页，选择场景预设与员工，点击「执行检测」即可看到画面、四路推理输出、决策链与中文复述。

## 接入真实 YOLOv8

```bash
pip install -r inference/requirements.txt
# 放置权重：detect.pt / cls_color.pt / cls_damage.pt / pose.pt
python inference/yolov8_service.py --source rtsp://... --port 8000
```

浏览器控制台执行：

```js
App.setSource('http://127.0.0.1:8000')
```

服务输出与前端完全一致的 JSON schema，决策链与界面无需改动。训练命令与权重说明见界面「系统说明与接入」页。

## 验收结果

- 12 个场景（未戴帽、裂纹、凹陷、帽檐缺口、错色、未系带、反戴、手持、倾斜、活体失败、阈值边界等）判定与真值 **100% 一致**。
- 500 次批量仿真：完整四任务方案漏放违规 **0** 次；传统「只看有没有帽」方案漏放 **295** 次。
- 场景真值按「场景 + 员工授权帽色」动态计算（安全总监戴红帽本来合规），避免统计口径误伤。
- 校验：`node --check` 通过、Python `py_compile` 通过、jsdom 真实 DOM 运行 0 报错、静态资源 HTTP 200。

## 部署建议

边缘侧 Jetson Orin Nano / 工控机 + TensorRT 或 OpenVINO，RTSP 取流，结果经 HTTP/MQTT 送闸机控制器与后台；断网时本地缓存白名单与阈值，恢复后补传日志。人脸照片与抓拍图按最小必要原则采集、加密存储、设置保留期与访问审计。
